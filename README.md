# Introduction

## Welcome to Elements

Elements is a no-code static website builder for macOS. It's designed to cater to all skill levels, whether you’re a beginner looking for simplicity or an experienced web developer needing advanced customisation, Elements offers the perfect balance. With its user-friendly interface and powerful features, you can create fast, efficient, and beautiful websites with ease.

Elements has everything you need built-in to build a beautiful modern website, and it's getting better all the time thanks to our passionate user base.

**Take a look at our** [**Getting Started Guide**](elements-app/getting-started.md) **to learn more about building websites with Elements.**
