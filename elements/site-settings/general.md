# General

Use the General project settings to set your website’s title and primary web address.

<figure><img src="../../.gitbook/assets/CleanShot 2025-06-01 at 7 .09.19@2x.png" alt="General Project Settings with fields for title, web address, language, logo and dark mode"><figcaption></figcaption></figure>

### Disabling Dark Mode

If your website doesn’t need a dark appearance, you can turn Dark Mode off by disabling the **Allow Dark Mode** toggle.
