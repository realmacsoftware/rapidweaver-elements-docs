# Project Settings

Project Settings contains the site-wide options for your website, including its title, logo, favicons, template code and publishing destinations.

Open Project Settings by clicking the cog icon in the toolbar.

<figure><img src="../../.gitbook/assets/CleanShot 2025-06-01 at 7 .16.00@2x.png" alt="Elements project window with the Project Settings toolbar button highlighted"><figcaption></figcaption></figure>

### Project Settings Sections

* [General](general.md) — Set the website title, primary address, language, logo, and appearance.
* [Web Icons](web-icons.md) — Configure favicons and related website icons.
* [Advanced Settings](advanced.md) — Control preview and project-level technical options.
* [Site Template](template.md) — Customise the HTML structure used during preview and export.

{% hint style="info" %}
Project Settings affect the whole website. Preview several pages after changing site-wide code, appearance, URLs, or publishing-related options.
{% endhint %}
