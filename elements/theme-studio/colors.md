# Colors

The colour settings allow you to manage a global colour palette for your website. You can add additional colours, and override theme defaults.

{% embed url="https://www.youtube.com/watch?v=R4OkJnd9JNw&t" %}

The colours specified in the Theme Studio can be chosen in a component. This can be anything from a font color to a background gradient.
