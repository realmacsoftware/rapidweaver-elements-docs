#### Manually styling links in lists

In the **Typography Component → Advanced**, add the following to **Classes**:

```css
[&_a]:!font-body
[&_a]:text-brand-500
[&_a]:underline-offset-2
[&_a:hover]:underline
```

This will style the links in any lists used within the Typography component.
