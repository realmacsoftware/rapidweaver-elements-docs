# Navigation and Interaction

These components help visitors move through the site, reveal content, and perform actions.

| Component | Use it for |
| --- | --- |
| [Accordion](accordion.md) | Showing collapsible groups of content. |
| [Breadcrumbs](breadcrumbs.md) | Showing the visitor’s position in the page hierarchy. |
| [Button](button.md) | Creating a clear action or destination. |
| [Content Slider](content-slider.md) | Presenting several component-based slides. |
| [Dropdown](dropdown.md) | Revealing a menu or compact group of choices. |
| [Menu](navigation-standard.md) | Building the site’s primary navigation. |
| [Modal](modal.md) | Opening focused content in a dialog. |
| [Reveal](reveal.md) | Showing content in response to an interaction. |
| [Tabs](tabs.md) | Switching between related content panels. |

Keep controls keyboard accessible, use clear labels, and ensure hidden content can be reached and understood without relying on hover alone.
