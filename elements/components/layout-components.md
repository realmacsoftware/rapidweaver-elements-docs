# Layout Components

Layout components create the structure that holds and positions the rest of your content.

| Component | Use it for |
| --- | --- |
| [Container](container.md) | Grouping components and controlling a section’s width, spacing, and layout. |
| [Divider](divider.md) | Adding a visual rule between sections or content groups. |
| [Flex](flex.md) | Arranging children in a flexible row or column. |
| [Grid](grid.md) | Building responsive rows and columns with precise placement. |
| [Text Wrap](text-wrap.md) | Flowing text around adjacent content. |

Start with Container for most page sections. Use Flex for one-dimensional alignment and Grid when rows and columns both matter.
