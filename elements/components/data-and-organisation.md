# Data and Organisation

These components organise repeated information or display content from structured sources.

| Component | Use it for |
| --- | --- |
| [CMS](cms.md) | Introducing content managed through Elements CMS. |
| [Filter](filter.md) | Showing content that matches a selected filter. |
| [Filter Tags](filter-tags.md) | Providing the controls used to choose filters. |
| [List](list.md) | Presenting ordered or unordered items. |
| [Table](table.md) | Displaying information in rows and columns. |
| [Top Pages](top-pages.md) | Listing pages from the project hierarchy. |
| [Tree](tree.md) | Presenting nested information or navigation. |

Choose the component whose structure matches the meaning of the content rather than using layout components to imitate lists or tables.
