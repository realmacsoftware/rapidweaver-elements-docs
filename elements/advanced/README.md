# Site Quality and Advanced

These guides cover the checks and technical files that help a published website remain accessible, discoverable, measurable, and correctly configured.

### Accessibility

[Accessibility](accessibility.md) explains how to make content and interactions usable by more people, including visitors using keyboards, screen readers, or reduced-motion settings.

### Search and Discovery

* [SEO](seo.md) — Improve page titles, descriptions, structure, and search presentation.
* [sitemap.xml](sitemap.xml.md) — Help search engines discover the pages in the site.
* [Robots.txt](robots.txt.md) — Provide crawl instructions for automated visitors.

### Analytics

[Analytics](analytics.md) covers adding visitor measurement and analytics code.

### Server Configuration

[.htaccess file](.htaccess-file.md) explains Apache-specific redirects and server rules.

{% hint style="warning" %}
Changes to analytics, robots rules, redirects, and server files affect the published website. Keep a copy of working settings and test important URLs after publishing.
{% endhint %}
