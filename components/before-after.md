# Before After

{% hint style="success" %}
The Before After component is only available as a **paid product via the Element Store.**
{% endhint %}

The Before After Component is a premium comparison tool built to drop straight into any Elements project. It gives you a clean, responsive slider that lets visitors drag to compare two images, or any other content. It’s perfect for agencies, photographers, designers, architects, and anyone who needs a clear visual before-and-after effect.

It’s more flexible than a basic slider. You can pair any components for the before and after content, customise the handle, switch between vertical or horizontal layouts, and rely on full touch support. Everything works out of the box and adapts smoothly to any screen size.
