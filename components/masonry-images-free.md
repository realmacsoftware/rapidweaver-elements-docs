# Masonry Images (Free)

[Masonry Images](elementsapp://storeProduct/com.elementsplatform.masonryimagespack) is a brand-new component for Elements that lets you lay out an entire folder of images in a responsive masonry grid.

Because it works directly from a resources folder, it’s incredibly fast to set up and easy to maintain. Add or remove images from the folder and your layout updates automatically.
