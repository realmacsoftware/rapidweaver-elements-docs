# Build a Sticky Menu

To make a menu sticky you need to put the menu and all site contents into  a container (site wrapper), and make the following chnages to the menu settings:

Layout > Position set to Sticky.

Layout > Z-Index > Custom set to 100.

Layout > Type > Uniform > Inset 0.
