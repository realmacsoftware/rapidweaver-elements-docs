# Downloading & Installation

### Download and Install Elements

First, you'll need to [Download Elements](https://www.elementsapp.io/?utm_source=element-docs) — look for the download button on the page. When the download is complete double-click to unzip the file, then move Elements.app to your Applications Folder.

### System Requirements

In order to run Elements you will need to meet the minimum requirements:

* Requires macOS 13 Ventura or newer.
* Apple Silicon or Intel based Mac.

Elements is built to work on all modern macs, so long as they meet the minimum requirements you'll be good to go.

### Getting Help

Should you have any questions about installation or registration you can post on the [Elements Support Forum](http://forums.realmacsoftware.com) and someone from the team will get right back to you.
