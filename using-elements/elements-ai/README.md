# Elements AI



{% hint style="warning" %}
**AI features in Elements are entirely optional.** You remain in full control of when and how it’s used.

If you prefer to work without AI, you can simply hide the AI Panel and continue building as usual.
{% endhint %}

### Elements MCP Server

The [Elements MCP Server](elements-mcp-server.md) lets compatible AI tools work with an open Elements project through a controlled integration.

#### Can I use my own AI API key?

Yes. Go to the Settings > AI tab in the Element Preferences and enter your API key for OpenAI and Anthropic/Claude.

{% hint style="info" %}
If you'd like to enable image generation into Elements, you'll need to add an OpenAI API key.
{% endhint %}
