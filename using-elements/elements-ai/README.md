# Elements AI

{% hint style="warning" %}
**AI features in Elements are entirely optional.** You remain in full control of when and how it’s used.

If you prefer to work without AI, you can simply hide the AI Panel and continue building as usual.
{% endhint %}

### Elements AI Assistant

The [Elements AI Assistant](elements-ai-assistant.md) lets you chat about your project and edit pages using your own OpenAI or Anthropic (Claude) API key. Add an OpenAI API key to enable image generation too.

### Elements MCP Server

The [Elements MCP Server](elements-mcp-server.md) lets compatible AI tools work with an open Elements project through a controlled integration.

### Can I use my own AI API key?

Yes. Open **Settings > AI > API Keys** in the Elements Preferences and add your **OpenAI** or **Anthropic (Claude)** API key. You can add keys for both providers. See [Elements AI Assistant](elements-ai-assistant.md) for the setup steps, privacy information, and billing details.

{% hint style="info" %}
Image generation requires an OpenAI API key.
{% endhint %}
