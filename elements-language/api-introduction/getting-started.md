# Getting Started

In this getting started guide we'll begin by creating a Custom Component inside of Elements and then look at migrating what we've built into an external DevElement.

## Creating a Custom Element

Creating a Custom Component in Elements is the fastest way to get started with exploring the Elements API. Custom Components can eaily be migrated to Distributable Element Packs at a later date.

Start a new Elements Project and go to the "Elements" area in the sidebar. Hit the "+" button next to the "Custom" heading.

## Creating an Element Pack

The boilerplate code for Element pack can be created inside of Elements, once created it can be edited in your favourite code editor.

### Component Categories

Every Component needs to have a defined category so Elements knows where to show it in the UI and users can easily find it. The following Categories are available, if you think we're missing one, pleae hop over to the [developer forum and let us know](https://forums.realmacsoftware.com/c/rapidweaver-elements/developer/).

* **Content**
  * e.g. Headings, Paragraphs, Lists.
* **Layout**
  * e.g. Grid, Flex, Containers, Coloumns.
* **Navigation**
  * e.g. Menus, Nav Bars, Breadcrumbs, Tabs, Pagination.
* **Forms**
  * e.g. Text Fields, Text Areas, Checkboxes, Submit Buttons.
* **SEO**
  * e.g. Keywords, SEO helpers.
* **Media**
  * e.g. Images, Video, Audio Players, Icons, Embeds (YouTube, Vimeo).
* **Ecommerce**
  * e.g. Cart Integration, Product display, Add to Cart Buttons.
* **Accessibility**
  * e.g. ARIA Lables, Contrast Checkers.
* **Animation**
  * e.g. Hover Effects, Animated SVG's.
* **Dynamic**
  * e.g. CMS Components.
* **Utilities**
  * e.g. Cookies, Anchors, Placeholders, Dividers.
* **Interactive**
  * e.g. Modals, Popovers, Accordians, Carousels.
* **Security**
  * e.g. Password Protection, Login Forms.
